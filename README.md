# もえのまいにち学習 v3.1 ― クラウド保存対応MVP（SQL v2整合版）

2026年11月23日更新。中学2年向け。スマートフォン/PCのWebブラウザで利用できます。

## 今できること

- 英語：1テーマ5日、3テーマ×5日=15レッスン（フレーズ3つ→3問クイズ→ChatGPT Live）
- 5教科：1教科3問×5=15問/日
- 1問ごとの選択肢・正誤・実施日を保存。DBは再挑戦の全履歴を保持し、画面の集計には最新回答だけを利用
- ChatGPT Liveの評価文をコピーして貼り付け、フレーズ活用/文法/応答（各1〜5）の点数を抽出して保存。評価不能なら空欄
- 保護者ログインで解答履歴、正答率、英会話評価を表示
- 「未接続の体験版」はこの端末のlocalStorage内に保存。クラウドへの自動移行なし

**まだ行っていないこと：** Supabaseの実プロジェクト作成、Web公開、実アカウントによる通信試験。これらには利用者側のSupabase設定と公開先が必要です。実際のChatGPT Liveとアプリは自動同期しません。発音の自動評価・会話の逐語録保存もしません。

## 最短の設定手順

1. [Supabase](https://supabase.com/) でアカウントを作成し、Freeプランで**新規プロジェクト**を作る。
2. Dashboard → **SQL Editor** → `schema.sql` の内容を一度実行する。**既存プロジェクトに入れる前に内容を確認**してください。
3. **Authentication → Users** で子どもと保護者の2ユーザー（メール＋パスワード）を作る。メール確認/パスワード発行については現在のSupabase画面の案内に従うこと。プライバシーを守るため **Authの一般公開サインアップは無効**にする。
4. Users一覧に出る各ユーザーの**User UID（UUID）**を控える。SQL Editorで次を実行（値は置き換える）。

   ```sql
   insert into public.learners(id,nickname)
   values ('子供のUser UID','もえ');

   insert into public.guardian_links(guardian_id,learner_id)
   values ('保護者のUser UID','子供のUser UID');
   ```

5. Dashboard → **Project Settings → API Keys**（または **Connect**）から **Project URL** と公開用 **publishable key**（旧形式なら `anon` key）を調べる。`config.js` の2か所へ入力する。

   ```js
   window.MOE_CONFIG = {
     supabaseUrl: "https://YOUR_PROJECT.supabase.co",
     supabaseAnonKey: "sb_publishable_..."
   };
   ```

   **厳禁:** `service_role`、`sb_secret_...`、DBパスワードを`config.js`やWeb上に置かないでください。公開キーの露出は想定されていますが、データ保護のためSQLの行レベルセキュリティ（RLS）は必須です。

6. `index.html`、`config.js`、`manifest.webmanifest`、`sw.js`、`icon.png` を**そのまま同じフォルダ**で公開する。静的サイトの公開先はCloudflare Pages、Netlify、GitHub PagesなどのHTTPS対応ホストを利用できます。**インターネットに公開されるURL自体は秘密にできません**が、学習記録はログインとRLSで制限します。
7. iPhoneのSafariで公開URLを開き、「共有」→「ホーム画面に追加」を選ぶ。メールアドレスとパスワードでログインするとクラウド保存になります。親はPCから同じURLへ別ユーザーでログインしてください。

## 保護者と子どもの権限

| 操作 | 学習者 | リンク済み保護者 | 未認証・第三者 |
|---|---:|---:|---:|
| 自分の解答を書く | ✅ | ✕ | ✕ |
| 自分の評価を書く/更新 | ✅ | ✕ | ✕ |
| 学習記録を読む | ✅ | ✅ | ✕ |
| 学習者/保護者を紐づける | ✕ | ✕ | ✕（管理者SQLのみ） |

※RLSは`schema.sql`にあります。**未接続の体験モードの履歴はクラウドではありません**。同じ端末で別の人が開ける可能性があるため、体験版には個人情報を書かないでください。

## Live連携（手動）

1. 学習画面から指示をコピー → 本人のChatGPT（無料アカウント可）のチャットに貼り付ける。
2. ChatGPTのLiveで約5分間会話。
3. 同じチャットのテキスト入力に「評価依頼をコピー」で得た文章を貼り付けて、ChatGPTの評価を生成。
4. アプリに戻り評価全文を貼り付けて「評価を保存する」。
5. 「Live練習できた / お休み」「今日の手応え」を選び、学習完了。評価は後からでも登録・編集できます。

Liveの文字起こしは音声の完全な記録ではなく、ChatGPTによる点数も学習用の参考値です。発音を自動採点していません。会話の全文や録音は本アプリのDBには保存しません。

## 拡張する場合

- 現在の固定教材15日分をDB上の教材管理テーブルに置き換えれば、月単位の増補・編集ができます。**現状、教材の差し替えはコード修正が必要です。**
- 学習ログは解答、英語の完了、Live評価を独立テーブルにしており、将来音声APIに切り替えても`live_reviews`に評価を継続保存できます。
- 日ごとの回答履歴は保存しますが、**再挑戦ボタン・苦手問題の自動再出題はまだ未実装**です。SQL v2は再挑戦の追記保存に対応していますが、既存画面では各問題の当日回答は1回です。
- 現在は「保護者1名→学習者1名」表示ですが、DBの`guardian_links`は複数学習者に拡張可能です。
- Plusの利用料金とは別にAPI利用料が発生するため、独自音声APIは継続利用が確認できた段階で検討します。

## 受け入れ確認

- 親ユーザーでログインし、子どもの成績と評価が表示されること。
- 子どもユーザーでログインし、3問に回答したあと別の端末で同じアカウントにログインして回答済み表示になること。
- 別の未リンクユーザーでは子どもの行が読めないこと。
- 保護者アカウントでは解答・評価の書き込みが拒否されること。
- オフライン中にクラウド保存できない場合、エラーが出ること（**クラウド未接続時のオフライン自動同期は未実装**）。
- Safariの「ホーム画面に追加」で起動できること。iPhone実機とSupabase実接続で最終確認が必要です。

## ファイル構成

- `index.html` : Webアプリ本体
- `config.js` : URL/公開用キー。**空欄だと端末内体験版**
- `schema.sql` : テーブル、RLS、参照権限
- `manifest.webmanifest`, `sw.js`, `icon.png` : iPhoneのホーム画面追加を支援


## この修正版の検証範囲

- SQL v2とアプリのテーブル名・列名・読み書き操作の対応を静的確認しました。
- 英語・5教科の履歴が複数件ある場合、UIの進捗には問題単位の最新1件を使用します。元の全履歴はDBに残ります。
- **Supabase実環境でのSQL実行・RLSの親子別ログインテストは未実施です。** Runの成功と権限テストを終えるまでは本番扱いにしないでください。
- SQL v2は新規空DB向けです。既に別版を実行したプロジェクトには、そのまま適用できません。
